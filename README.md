# south_african_property_market_analytics
Provincial and metropolitan residential property market analysis in South Africa using Python, statistical analysis, forecasting and Power BI.
Project Overview

This project analyses historical South African Residential Property Price Index (RPPI) data to investigate residential property market trends, regional differences, property-type performance, historical growth patterns and market stability.

Using Python for data preparation, feature engineering, statistical analysis and forecasting, alongside Power BI for interactive visualisation, the project aims to turn historical index data into insights that can support property-market analysis and investment research.

The analysis covers provincial and metropolitan markets using monthly observations from 2010 to April 2026.
